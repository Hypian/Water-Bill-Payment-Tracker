# Design Brief

## Personality
Clean, trustworthy, calm - a utility app people can rely on.

## Palette
| Token | Hex | Use |
|-------|-----|-----|
| --primary | #0b6e99 | Buttons, links |
| --primary-dark | #084c6b | Header |
| --accent | #19b5a5 | Success |
| --warn | #e0a100 | Due soon |
| --danger | #d64545 | Overdue / errors |
| --bg | #f4f8fa | Background |
| --text | #1d2b36 | Body text |

## Typography
System font stack (no downloads). Base 16px.

## Layout
Mobile-first single column, cards, max width 960px on desktop. Top nav on desktop, simple stacked nav on mobile.

## Components
Card, status badge (Paid/Unpaid/Overdue), table, form, toast message.

## Screens (v1)
Login/Register, Dashboard, Bills, Pay, History, Meters, Admin (Enter Reading + stats).

## Accessibility
Contrast >= 4.5:1, labels on every input, visible focus, status shown with text and not colour alone.
