# WaterBill Tracker
Water bill payment & history tracker (Node/Express + SQLite + vanilla JS).

    cd server
    npm install
    cp .env.example .env
    npm run seed     # creates admin@demo.rw / admin123 and customer@demo.rw / user123
    npm start        # http://localhost:3000

Docs are in `/docs`. Change tariff in `server/tariff.js`.
